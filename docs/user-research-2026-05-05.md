## 1. 調査方法 (Methodology)

### 期間
- 一次（X 日本語）: 直近 1 年程度を狙ったが、X 直接アクセスは制限あり（後述）
- 二次（Reddit / EA Forums）: 直近 1 ヶ月〜数ヶ月
- 任意（日本語ブログ・wiki・知恵袋・アプリレビュー）: 投稿日問わず（既存資料の生存性確認が目的）

### 使用クエリ（代表）
- X: `site:x.com SWGoH 銀河の英雄`, `+ モッド/ギア/GAC/TW/TB/Conquest/引退/課金/ギルド/萎える/つまらない/不満`
- Reddit: `site:reddit.com r/SWGalaxyOfHeroes <topic>`, `reddit SWGalaxyOfHeroes <topic>`
- 日本語: `銀河の英雄 攻略 ブログ 2026`, `銀河の英雄 翻訳 不自然`, `site:chiebukuro.yahoo.co.jp 銀河の英雄 ...`

### 調査ソース実態（取れた / 取れなかった）

| ソース | 結果 | メモ |
|---|---|---|
| **X (Twitter) 個別ツイート WebFetch** | ❌ 全て HTTP 402 | 個別ポストの本文は WebFetch 不可。Google snippet 経由のみ |
| **X (Twitter) Google site: 検索** | △ ヒットあり、ただし大半はアカウント TOP | 本文プレビューが取れたのは数件。サダ・五右衛門・frisk・ホロくん・ミスターポッポ等の主要日本人アカウントが検索に出る |
| **Reddit 直接 fetch (www.reddit.com)** | ❌ Claude Code 側でブロック | `unable to fetch from www.reddit.com` |
| **Reddit ミラー (lr.mint.lgbt, lurrker.com)** | ❌ ECONNREFUSED | フォールバック失敗 |
| **Reddit Google snippet** | △ 結果は出るが本文プレビューは限定的 | `site:reddit.com r/SWGalaxyOfHeroes <keyword>` は 0 件多発、無 site: なら snippet あり |
| **EA Forums (forums.ea.com)** | ✅ 完全 fetch 可能 | 直近スレッド一覧・スレッド本文・コメントまで取れた。Reddit の代替として最も有用 |
| **YouTube コメント** | ❌ コメント部分はレンダリング前で取れず | ナビと著作権表記しか抽出できない |
| **Disboard (Discord 鯖一覧)** | ❌ HTTP 403 | Discord 公開鯖は対象外 |
| **日本語ブログ (ChipTips / swgohfod / starwars-gamer-blog / swgoh.blog.jp 過去記事)** | ✅ 本文 fetch 可能 | 後述の生存性も判明 |
| **日本語 wiki (swgohjp.info)** | ✅ ただし 2022/10 で更新停止 | 構造のみ確認 |
| **Yahoo!知恵袋** | ✅ 個別 Q&A 本文を verbatim で取得可能 | 質問者・回答者・お礼までセットで取れる |
| **APPLION / app-ranking.net (アプリレビュー)** | ✅ ★別レビュー本文を verbatim で取得可能 | 本調査で最も生声を稼いだソース |
| **GameWith 雑談・質問掲示板** | ✅ 投稿者名（無名）・日付・本文を抽出可能 | ただし投稿頻度は低め（直近 1 年で約 20 件） |

## 4. Limitations

### 4.1 サンプリングバイアス
- **アクティブ層偏重**: X / アプリレビュー / Yahoo知恵袋 / EA Forums / GameWith のいずれも、能動的に発信する層しか拾えていない。**サイレントマジョリティ／離脱済み層の現在の声は本質的に拾えていない**
- **不満系バイアス**: APPLION・app-ranking のレビューは★1〜2 を意図的に多く抽出した。同サイトの全体評価は★4 平均なので、「日本人プレイヤーの過半数が不満」と推論するのは誤り
- **時系列バイアス**: 一部 finding（A-08, B-05, B-06, G-03 など）は 2017-2020 のもの。現在も同問題が続いているかは未検証
- **重複話者バイアス**: 同一 X アカウント（@friskswgoh, @Cooking_sadaSW 等）が複数クエリで出現。少数の高頻度発信者の声を母集団として扱う危険性
- **アンサーバイアス**: Yahoo知恵袋の回答者 CC-5576-39 さんが複数質問に回答しており、特定回答者の見解が日本語コミュニティ全体の視点として過大表現される可能性

### 4.2 ツール上アクセスできなかった情報源
- **X 個別ツイート本文 (WebFetch HTTP 402)** — Google snippet 経由で部分取得のみ
- **www.reddit.com 直接 fetch (Claude Code 側ブロック)** — Reddit 一次データ大幅欠落
- **Reddit ミラー (lr.mint.lgbt, lurrker.com) ECONNREFUSED** — フォールバック失敗
- **YouTube コメント** — レンダリング前のためコメント本文取得不可
- **Discord 公開サーバー (Disboard 403)** — 対象外
- **Google Play / App Store 内のレビュー** — 直接 fetch 不可（APPLION 経由の二次情報のみ）
- **2026 年の日本語 X 投稿** — 取得できた特定ツイートは全て 2020〜2024 年のものか日付不明。直近 1 年の日本人 voice はほぼ取れていない

### 4.3 解釈上の限界
- 「英語圏で頻出する不満が日本でも当てはまるか」の仮説検証は、日本語サンプル不足のため**確定できていない**。E-04 と E-01〜03 のように対応を確認できた項目もあるが、構造的な比較研究には至らない
- 引退率・継続率・課金率といった**定量データは一切ない**。本調査は質的調査に留まる
- 「GP 2M / 9M / 10M+」は finding 内の言及から拾った数字であり、層別の人数比・活動比は推定不可
- 課金額（A-06）は主観的レビューの引用であり、実態の客観的検証なし
