# swgoh4jp.com 成長戦略 (2026-05-06)

> ユーザー調査（2026-05-05）・競合調査・Q8 モッドニーズ調査・Twitter/X 調査の結果に基づく。  
> **前提制約: SNS アカウント運用なし（デジタルデトックス）。流入はすべてオーガニック検索のみ。**

---

## 1. ペルソナ定義

調査データから識別できる 3 層。人数比は不明だが Layer 1 が最多と推定。

### Layer 1 — SW 入門・カジュアル層

| 項目 | 内容 |
|---|---|
| 推定 GP | 1〜3M |
| 動機 | スターウォーズが好き、お気に入りキャラを育てたい (J-04, J-05) |
| 行動 | PC ブラウザで「キャラ 調べる」「用語 わからない」を検索 |
| 困りごと | モッドの意味がわからない (B-08〜B-12)、次に何をすべきかわからない (B-02, B-07) |
| swgoh4jp との接点 | `/characters` を図鑑として閲覧、ガイド記事の検索流入 |

### Layer 2 — 中堅プレイヤー

| 項目 | 内容 |
|---|---|
| 推定 GP | 2〜7M |
| 動機 | GAC・TW で勝ちたい、ギルドに貢献したい |
| 行動 | パーティ構成・カウンター編成を調べる (C-05)、Discord 不要なギルドを探す (G-01) |
| 困りごと | GL 取得への遠さ、最新メタへの追従 |
| swgoh4jp との接点 | `/TWCounters`、GAC 攻略ガイド記事、`/advisor` |

### Layer 3 — 上位・長期プレイヤー

| 項目 | 内容 |
|---|---|
| 推定 GP | 7M+ |
| 動機 | マネタイズ批判しながらも継続 (A-03, H-04)、コミュニティ情報を追う |
| 行動 | EA Forums・ChipTips で英語情報を読む、X で発信する |
| 困りごと | Coliseum バグ・補償の質 (E 系)、リソース最適化 (A-01) |
| swgoh4jp との接点 | 現状は薄い。ニュース速報・マクロ分析があれば来る可能性 |

### ターゲット優先順位

**Phase 3（今）: Layer 1 ≫ Layer 2**  
Layer 1 は検索ニーズが明確でコンテンツ空白が大きい。Layer 3 はコスト高・ニーズ複雑で後回し。

## 2. 成長戦略（SEO 純粋依存）

### なぜ SEO だけで戦えるか

1. **競合が古い**: 日本語 SWGoH コンテンツの大半が 2018〜2022 年。2025〜2026 年の空白が大きい
2. **wiki が死んでいる**: swgohjp.info が 2022年10月で停止 → 体系的な日本語情報源が空白
3. **「銀河の英雄 用語 一覧」が別作品に汚染**: 「銀河英雄伝説」が占拠。SWGoH 専用記事を書けば即座にトップを取れる
4. **DB ページが多数ある**: `/characters` + `/ships` で 200+ URL が既に存在 → ロングテール SEO の土台あり

### 成長ファネル

```
検索流入（ガイド記事）
    ↓
サイト内回遊（記事 → キャラ詳細 → 関連記事）
    ↓
リピーター化（ブックマーク・定期訪問）
    ↓
PV 増加 → 1,000 PV/月 → Patreon
```

SNS を使わないため「シェアによる拡散」は期待しない。検索→回遊→リピートのループを SEO で回す。

## 3. コンテンツロードマップ

### Phase 3-A: 即効性の高い空白埋め（優先 3 本）

#### 記事 1: SWGoH モッド完全ガイド（初心者向け）2025年版
- **狙うキーワード**: 「銀河の英雄 モッド 種類」「銀河の英雄 モッド 初心者」
- **競合**: 2018年の記事のみ。更新記事はゼロ
- **内容**: 6形状・8セット・レア度・スピード優先の理由・モッドチャレンジ入手
- **Layer 1 の finding**: B-09（モッド形状と性能の混同）、B-10（モッド解説がどこかわからない）

#### 記事 2: SWGoH ステータス・用語辞典
- **狙うキーワード**: 「銀河の英雄 ヘルスティール とは」「銀河の英雄 用語 一覧」
- **競合**: 「用語一覧」は別作品「銀河英雄伝説」に汚染 → SWGoH 専用記事で独占可能
- **内容**: スピード・ヘルスティール・有効性・抵抗力・クリティカル率・クリティカルダメージ等
- **Layer 1 の finding**: B-08（ヘルスティールとは？知恵袋 1 件のみ）

#### 記事 3: GAC チーム編成入門（GL なし層向け）2025年版
- **狙うキーワード**: 「銀河の英雄 GAC 攻略」「銀河の英雄 チーム 編成」
- **競合**: 2020年の記事が上位。ChipTips の格付けリストはあるが「入門」がない
- **内容**: コロシアム後のメタ概要、GL なし層の防衛・攻撃チーム 5 選
- **Layer 2 の finding**: C-05（パーティ攻略相談ニーズ）

### Phase 3-B: 体系化（次の 2 本）

#### 記事 4: バフ・デバフ完全一覧 2025年版
- wiki が 2022年停止、ChipTips の `status_effects.php` は JS 依存でクロール困難 → 静的 MDX で差別化
- `/characters` の内部リンク先として機能させる

#### 記事 5: 初心者が最初に育てるべきキャラ 2026年版
- 「銀河の英雄 キャラ 育成 おすすめ」の上位を汎用サイトから奪う
- `/characters` の各キャラ詳細ページへの内部リンクハブになる

### コンテンツ方針

- すべて **MDX** で `/guides/[slug]` に配置（Phase 3）
- **常緑コンテンツ優先**（「2025年版」は付けても内容は基本システム解説）
- 内部リンクを意識: 記事 ↔ キャラ詳細 ↔ 記事 の三角形
- 画像: スクリーンショット + 説明テキスト（重さ管理）

## 4. 機能ロードマップ

| 優先度 | 機能 | 理由 |
|---|---|---|
| 🔴 高 | `/guides/[slug]` MDX ルート | コンテンツ記事の土台。これがないと Phase 3-A に入れない |
| 🟡 中 | キャラ詳細 ↔ ガイド記事の内部リンク | 回遊率・サイト内滞在時間の向上 |
| 🟡 中 | favicon・ロゴ・OGP 画像の刷新 | ブランド認知（SNS なしでもブックマーク時に効く） |
| 🟢 低 | per-page 動的 OGP + 日本語フォント | シェア品質向上。SNS なしでは優先度落ちる |
| 🟢 低 | GitHub Actions 週次 sync PR | 新キャラ追加の自動化。今は手動で十分 |

## 6. やらないこと（明示的スコープ外）

- SNS アカウント運用（X/Twitter・Instagram・TikTok 等）
- ギルド検索機能（Layer 2 ニーズだが開発コスト高）
- プレイヤープロフィールページ（Comlink API は実装済みだが PV 優先フェーズでは不要）
- 英語コンテンツ（日本語差別化が軸）
- 障害情報集約（リアルタイム対応が必要で運用負荷大）
