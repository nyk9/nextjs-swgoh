SWGoH（Star Wars: Galaxy of Heroes、日本語版「銀河の英雄」）は用語が多いゲームです。同じ「ヘルス・スティール」「有効性」が攻略記事の中で当たり前に出てきますが、初心者にとっては最初の壁になります。この記事は、ゲームを始めたばかりの人が攻略情報を読めるようになるための **用語辞典** です。

カテゴリごとに「何のための数値か」「どう影響するか」を中心に解説します。具体的な数値（◯%）はバランス調整で変わるため、本文では原則として割合の絶対値ではなく **役割** を説明します。

> 数値や効果はゲームのアップデートで調整されることがあります。最新の値はゲーム内のキャラクター詳細画面で必ず確認してください。

## 第1章: 戦闘の基本ステータス

キャラクター詳細画面の「ステータス」タブに表示される値です。最初に覚えるべきものから順に並べます。

### スピード

そのキャラクターが行動する速さを表す値です。SWGoH における **最重要ステータス** で、スピードが高いキャラほど早く・多く行動できます。

ゲームの戦闘は「ターンメーター（後述）」という見えない数値で進みます。スピードが高いほどターンメーターが早く溜まり、結果として敵より先に攻撃したり、行動回数が多くなったりします。

モッドガイドでも繰り返し書きましたが、「迷ったらスピードを上げる」が SWGoH の基本ルールです。詳しくは [SWGoH モッド完全ガイド](/guides/swgoh-mod-guide-2026) を参照してください。

### 体力（HP）と プロテクション

どちらも **やられるまでに耐えられるダメージ量** を示す数値ですが、扱いが少し違います。

- **体力**: 0 になると戦闘不能
- **プロテクション**: 体力の前に削られる「予備の盾」。0 になっても戦闘不能にはならず、その後は体力が削られる

戦闘中はまずプロテクションが削られ、それが尽きてから体力に削りが入ります。バトル間（後述のレイドや TW などのギルドイベント）ではプロテクションが回復するルールが多く、体力よりも「使い切ってもいい一時資源」として扱われます。

### 攻撃力（フィジカル / スペシャル）

攻撃ダメージのもとになる数値です。

- **フィジカル攻撃力**: 通常攻撃などの物理スキルに使われる
- **スペシャル攻撃力**: フォース攻撃や爆発などの特殊スキルに使われる

スキルごとにどちらを使うかは決まっています。同じキャラでも通常攻撃はフィジカル、特殊攻撃はスペシャルというパターンが多いです。

### 防御力（装甲 / 抵抗力）

被ダメージを軽減する値です。攻撃が物理か特殊かで参照する値が変わります。

- **装甲**: 物理攻撃を受けたときの軽減率に変換される
- **抵抗力**: 特殊攻撃を受けたときの軽減率に変換される

注意: ここで言う「抵抗力」は **防御寄りの抵抗力** で、後述するデバフ耐性の「抵抗力（テナシティ）」とは別の概念です。日本語で同じ単語が当てられているため混乱しがちな点です。

### 防御突破力

相手の防御力を一定量無視する値です。装甲が高い相手には、攻撃力を上げるよりも防御突破力を上げたほうがダメージが伸びることがあります。

### クリティカル率 と クリティカルダメージ

- **クリティカル率**: 攻撃が「クリティカルヒット」になる確率
- **クリティカルダメージ**: クリティカル時のダメージ倍率

クリティカル率を上げるほどクリティカルが出やすく、クリティカルダメージを上げるほどクリティカルが出たときのダメージが大きくなります。両方を一緒に上げるほど期待ダメージは伸びる関係です。

平均ダメージの目安は次の式で計算できます。

```
平均ダメージ = ダメージ × ((クリティカル率 × (クリティカルダメージ - 1)) + 1)
```

例: ダメージが2,000、クリティカル率が50%、クリティカルダメージが180% のとき、

```
2,000 × ((0.5 × (1.8 - 1)) + 1) = 2,800
```

「クリティカル率を 0% から 50% に上げる」ことと「クリティカルダメージを 150% から 200% に上げる」ことの効果はだいたい同じくらい、というのがこの式の使いどころです。

### クリティカル率耐性 / 回避力 / 弾き

被ダメージ側のステータスです。

- **クリティカル率耐性**: 敵のクリティカルが発生する確率を下げる
- **回避力（Dodge）**: 物理攻撃を回避する確率
- **弾き（Deflection）**: 特殊攻撃を回避する確率
- **命中力（Accuracy）**: 相手の回避力と弾きを貫通する

通常はキャラ独自のスキルで一時的に発生する効果として登場します。

### 有効性 と 抵抗力（テナシティ）

弱体（デバフ）が成立するかどうかを決めるステータスです。

- **有効性（Potency）**: 自分が **デバフを与える** 成功率を上げる
- **抵抗力（テナシティ / Tenacity）**: 敵が与えてくるデバフを **耐性発揮で打ち消す** 確率を上げる

仕組みとしては、デバフを与える側の有効性が高ければ通り、受ける側の抵抗力が高ければ「耐性発揮」と表示されて防げる、というシンプルな関係です。

ただし、抵抗力には **絶対下限の最低値** が設定されており、有効性をいくら積んでも 100% で必中にはなりません。これは長らく 15% と言われてきた値です。最新の数値はバランス調整の対象になり得るので、ゲーム内で確認してください。

なお、注意点として **すべてのデバフが抵抗力で防げるわけではありません**。スキルの説明文に「デバフを発生させる」と書かれているものは抵抗力で防げますが、「ターンメーターを減少させる」「強化効果を解除する」のような効果は別判定で、抵抗力が無関係なケースもあります。

### ヘルス・スティール

与えたダメージの一定割合を **自分の体力として回復** する効果です。日本語の正式表記は「ヘルス・スティール」（中黒あり）です。

仕組みのポイント:

- ヒットごとに発動する。多段攻撃なら各ヒットで個別に発動する
- 攻撃のダメージそのものを増やすわけではない。あくまで自分が回復するだけ
- 「回復不可」状態などで回復できない条件下では効果が消える場合がある

戦士・タンク役のキャラはギア・レリックの上昇で自然に伸びるため、序盤は意識して積む必要は少ないです。

## 第2章: ターンメーター

戦闘の **行動順を決める内部ゲージ** です。すべての戦闘はこの仕組みで進みます。

### 仕組み

- 各キャラはバトル開始時にターンメーター 0 でスタート
- 毎ティック、自分の **スピード分** だけターンメーターが増える
- 1,000 に到達したキャラから順番に行動する
- 行動が終わるとターンメーターは 0 に戻る

つまり「スピード 200 のキャラはスピード 100 のキャラの 2 倍の頻度で行動する」が直感的に成り立ちます。

### ターンメーター操作

スキル説明には次のような表現がよく登場します。

- **ターンメーター上昇**: 該当キャラのゲージを進める。1,000 を超えても繰越されない（上限が 1,000）
- **ターンメーター減少**: 敵のゲージを後退させる
- **ボーナスターン**: 通常のターンメーター進行とは別枠で即座に行動権を得る

スピードと並んで「ターンメーターをいかに自分側に偏らせるか」が SWGoH の戦闘設計の核です。

## 第3章: 強化効果（バフ）と 弱体（デバフ）

スキルがキャラに付与する **状態異常** です。日本語のゲーム内表記では、有利な効果を「強化効果」、不利な効果を「弱体」と呼びます。「バフ・デバフ」はコミュニティでの通称です。

ここでは初心者が攻略記事を読むうえで頻出する主要なものだけを紹介します。

### 主要な強化効果（バフ）

| 表記 | 意味 |
|---|---|
| スピード上昇 | 一定時間スピードが上がる |
| 攻撃力上昇 | 攻撃力が上がる |
| 防御力上昇 | 防御力が上がる |
| クリティカル率上昇 | クリティカル率が上がる |
| クリティカルダメージ上昇 | クリティカルダメージが上がる |
| 有効性上昇 | 有効性（デバフ命中）が上がる |
| 抵抗力上昇 | 抵抗力（デバフ耐性）が上がる |
| ヘルス・スティール上昇 | ヘルス・スティールが上がる |
| 防御突破力上昇 | 防御突破力が上がる |
| ボーナスプロテクション | 一時的にプロテクションが追加される |
| 挑発（タウント） | 敵から狙われ続ける状態。味方をかばう役 |
| ステルス | 直接ターゲットされなくなる |
| フォアサイト | 次に受ける攻撃を 1 回必ず回避する |
| 報復効果（リトリビューション） | 反撃確率が大きく上がる |
| 強化効果獲得不可 | 不利な意味の「バフを得られない」状態 |

### 主要な弱体（デバフ）

| 表記 | 意味 |
|---|---|
| スピード低下 | スピードが下がる |
| 攻撃力低下 | 攻撃力が下がる |
| 防御力低下 | 防御力が下がる |
| 有効性低下 | 有効性が下がる |
| 抵抗力低下 | 抵抗力が下がる |
| スタン | 1 ターンの間、行動できない |
| よろめき | アシスト・反撃・ボーナスターンが封じられる |
| エクスポーズ | 攻撃を受けるたびに体力にダメージを受ける |
| バーン（炎上） | ターン経過でダメージを受ける |
| デスマーク | 受けるダメージや復活制限などのペナルティ |
| シャッターポイント | ターゲットされやすくなり、被ダメージが伸びる |
| 恐怖 | ターン中に行動できないなどの強い行動制限 |
| めまい | 攻撃が外れる |
| スキルブロック | 特殊スキルが使えなくなる |
| 無防備状態 | 一定の効果から守られない状態（命中保証など） |

これらの効果のうち、スキル説明に「弱体を発生させる」と書かれているものは抵抗力で耐性発揮の対象になります。「効果」「状態」と記述されているものは判定が異なる場合があるので、スキル本文を必ず読みましょう。

## 第4章: キャラクター進化システム

1 体のキャラを強くする経路は複数あります。

### レアリティ（星）

1〜7 ★ で表されます。同名キャラでも、星の数が違うと基礎能力もスキルアンロックの可能性も変わります。多くのアリーナやイベントで **7★** が事実上の前提です。

### キャラクターレベル

最大は **プレイヤーレベルと同じ** までしか上げられません（プレイヤーレベル 85 ならキャラ最大も 85）。

### ギア（装備）

**ギアレベル 1〜13** まで段階的に強化します。各段階で 6 つのアイテムスロットを埋めるのが基本ループです。後半になるほど素材集めがボトルネックになります。

### レリック（Relic）

ギアレベル 13 到達後に解放される、追加進化システムです。**最大はレリックレベル 10**（2025年11月の10周年アップデートで 9 から 10 に上限拡張）。

レリックは基礎属性（STR / AGI / TAC、本章末で解説）を伸ばし、結果として体力・装甲・物理クリティカル率・抵抗力（防御寄り）・特殊ダメージ・物理ダメージなどが連動して上がります。「もう一段強くしたい」フェーズの主役です。

### 補足: 基礎属性 STR / AGI / TAC

- **Strength (STR / 力)**: 体力と装甲を上げる
- **Agility (AGI / 機敏)**: 物理クリティカル率と装甲を上げる
- **Tactics (TAC / 戦術)**: 物理・特殊攻撃力と抵抗力（防御寄り）を上げる

レリックのレベルアップやキャラごとのキット記述で参照される、いわば「裏のステータス」です。

## 第5章: アビリティ（スキル）強化材料

スキルレベルを上げる素材には種類があり、最終段階だけ特殊です。

### ゼータ（Zeta）

通常キャラのスキルに対する **最強強化** に使う素材。一部の特殊スキル・リーダースキル・ユニークスキルにのみ要求され、効果が大きく変わるか、新しい挙動が追加されます。

### オミクロン（Omicron）

特定のゲームモード（テリトリー・ウォー、テリトリー・バトル、グランド・アリーナ等）でのみ発動する強化です。汎用ではなく **限定モード用ブースト** と理解するとわかりやすいです。

### アルティメット（Ultimate）

**ギャラクティック・レジェンド**（後述）専用の強化素材で、戦闘中チャージして発動する切り札スキルを解放します。

## 第6章: ゲームモード一覧

このサイトの [TW カウンター](/TWCounters) など、各モードの名前を把握しておくと攻略記事や別ツールが読みやすくなります。

### スカッド・アリーナ

5 体編成で他プレイヤーの防衛チームに挑む基本 PvP。最終的なランキングが日次の報酬になります。

### フリート・アリーナ

艦隊（艦船 + 増援）を使う PvP。スカッド・アリーナの艦船版です。プレイヤーレベル 60 で解放されます。

### ギャラクティック・ウォー

12 戦のソロ PvE。負傷したキャラのダメージは次戦に持ち越されるため、ロースター全体の幅が問われます。

### コンクエスト

プレイヤーレベル 85 で解放される長期 PvE。月 1 回・約 2 週間のサイクルで、報酬として強力な装備・新キャラのシャードが得られます。

### テリトリー・バトル

ギルド全員参加の協力型 PvE。ライトサイド・ダークサイド・**ライズ・オブ・ジ・エンパイア（RotE）** などの種類があり、6 日間 6 フェーズの構成です。

### テリトリー・ウォー

ギルド対ギルドの PvP。Preview / Setup / Attack の 3 フェーズで、それぞれ 24 時間程度。攻撃用と防衛用に編成を分ける戦略性が肝です。

### グランド・アリーナ・チャンピオンシップ（GAC）

レート式の 1 対 1 PvP。複数日のラウンドを通して、3 つの防衛拠点と攻撃ロースターを編成して戦います。最上位帯ではキャラの数値より「マッチアップ理解」が問われます。

### ギャラクティック・レジェンド（GL）イベント

最強カテゴリのキャラクター解放イベント。多くの 7★ キャラを揃える前提で、Tier 1〜6 を順にクリアし、最終 Tier でアルティメット解放素材が報酬になります。

### コロシアム（2025年11月追加）

10周年アップデートで導入された新モード。プレイヤーレベル 10 で解放される **Era モード** の第 1 弾で、Era システム（後述）の入口です。

### Era システム / Era チャレンジ

10周年アップデートで Galactic Challenges を置き換えた仕組み。各 Era のテーマに沿った Marquee キャラ・週間クエスト・Era チャレンジで構成され、Era ごとに進行する形になりました。

## 第7章: 通貨・コア用語

### 通貨

| 名前 | 主な使い道 |
|---|---|
| クリスタル | 課金・最重要資源。エネルギー回復、デイリーパス、ストアでの購入 |
| クレジット | レベルアップ・スキル強化・装備に使う共通通貨 |
| アライポイント | フレンドの貸し借りやブロンジウム・データカードに使う |
| ギルドトークン | ギルド活動で稼ぎ、ギルドストアで装備類と交換 |
| エネルギー | キャンペーン挑戦に必要なスタミナ。時間で回復、クリスタルで補充可 |
| キャンティーナ・エネルギー | キャンティーナバトル用の別系統エネルギー |

### コア用語

- **アライ・コード（9 桁）**: 各プレイヤー固有の ID。フレンド申請やこのサイトの [AI 育成アドバイザー](/advisor) でも入力に使う
- **キャピタル・シップ（旗艦）**: フリートの中核となる艦船。ウルティメット級の固有スキルを持つ
- **増援（リインフォースメント）**: フリート戦で控えとして参戦する艦船
- **データクロン**: 2022 年導入の PvP 専用ブースト。3 ヶ月でローテーションし、特定派閥のチームを強化する
- **マーキー（Marquee）**: 新キャラ初登場の数日限定イベント
- **ジャーニー（Journey）**: 既存の特定キャラを揃えると進化先キャラを獲得できるイベント

## まとめ

ここまで読めば、SWGoH の攻略記事や Twitter の議論で出てくる用語の **8 割** はわかるはずです。残り 2 割はキャラクター固有の特殊効果（例: 「ジェダイ・レガシー」「マスタープラン」など）で、これは個別キャラのスキル説明を読むしかありません。

このサイトの [キャラクター図鑑](/characters) と [艦隊図鑑](/ships) では、各キャラの日本語スキル説明を確認できます。「このキャラのこのスキル、何の効果？」と思ったときに辞書代わりに使ってください。

> 数値・効果・モードの仕様はアップデートで変わります。本文では変動しやすい絶対値を避けていますが、最新の正確な情報はゲーム内 UI を最終ソースとしてください。
