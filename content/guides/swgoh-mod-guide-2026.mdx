モッドは SWGoH の強さを決める最重要要素です。同じキャラクターでもモッドの質で強さが大きく変わります。このガイドでは「モッドって何？」という入門から、スライスや入手方法まで順を追って説明します。

## モッドとは

モッドはキャラクターに装備できる強化アイテムです。プレイヤーレベル **50** で解放され、1キャラクターにつき **6枚** まで装備できます。装備するとスピード・体力・攻撃力などのステータスが上昇します。

---

## 第1章: 6つのスロットと形状

キャラクターの6スロットにはそれぞれ「形状（シェイプ）」が固定されており、形状によって選べるプライマリスタット（主要ステータス）が決まります。

| スロット（正式名） | 通称 | 選べるプライマリ |
|---|---|---|
| Square（Transmitter） | スクエア | 攻撃力%（固定・1択） |
| Arrow（Receiver） | アロー | スピード / 精度% / クリティカル回避力% / 攻撃力% / 防御力% / 体力% / プロテクション%（7択） |
| Diamond（Processor） | ダイヤモンド | 防御力%（固定・1択） |
| Triangle（Holo-Array） | トライアングル | クリティカルダメージ% / クリティカル率% / 攻撃力% / 防御力% / 体力% / プロテクション%（6択） |
| Circle（Data-Bus） | サークル | 体力% / プロテクション%（2択） |
| Cross（Multiplexer） | クロス | 有効性% / 抵抗力% / 攻撃力% / 防御力% / 体力% / プロテクション%（6択） |

### 最重要ポイント

**スピードをプライマリに選べるのはアロースロットのみ**です。スピードを最大化したいなら、アローには必ずスピードプライマリを装備してください。これが初心者がまず覚えるべき最初のルールです。

同様に、**クリティカルダメージプライマリはトライアングルのみ**に存在します。

## 第2章: セット効果（8種類）

6枚のモッドには「セット」の種類があり、同じセットを2枚または4枚そろえると追加ボーナスが発動します。ボーナスはモッドをレベル15まで上げたときに最大値になります。

| セット名 | 必要枚数 | Lv15 最大ボーナス |
|---|:---:|---|
| 体力 | 2枚 | HP +5% |
| 防御力 | 2枚 | 防御力 +5% |
| クリティカル率 | 2枚 | クリティカル率 +5% |
| 抵抗力 | 2枚 | 抵抗力 +10% |
| 有効性 | 2枚 | 有効性 +10% |
| クリティカルダメージ | 4枚 | クリティカルダメージ +30% |
| 攻撃力 | 4枚 | 攻撃力 +10% |
| **スピード** | **4枚** | **スピード +10%** |

### セットの組み方

6スロットの組み合わせには2パターンあります。

- **4枚セット × 1 + 2枚セット × 1**（例：スピード4枚 + 体力2枚）
- **2枚セット × 3**（例：クリティカル率2枚 + 有効性2枚 + 体力2枚）

多くのアタッカーには「スピード4枚 + クリティカルダメージ4枚」が使えないため、「スピード4枚 + 体力2枚」や「クリティカルダメージ4枚 + クリティカル率2枚」が定番です。

## 第3章: レア度（ドット数）とカラー

モッドには2つの品質軸があります。

### ドット数（1〜6）

ドット数 = レアリティです。6ドットが最高で、プライマリスタットの数値が最大になります。

- **6ドットのモッドを装備するにはキャラのギア12 + 7星が必要**
- 1〜4ドットはそのままで固定（アップグレード不可）
- 5ドットは「スライス」によって6ドットに昇格できる（第6章で解説）

### カラー（ティア）

カラーはモッドの初期品質を表します。スタート時のセカンダリスタット数が変わります。

| カラー | ティア | 初期セカンダリ数 |
|---|---|:---:|
| グレー | E | 0個 |
| グリーン | D | 1個 |
| ブルー | C | 2個 |
| パープル | B | 3個 |
| ゴールド | A | 4個（最高） |

ゴールドのモッドは最初からセカンダリが4つ揃っているため、どのセカンダリが付くかを早い段階で確認できます。

## 第4章: スピードはなぜ「聖杯」なのか

英語圏のプレイヤーはスピードを"The Holy Grail"（聖杯）と呼びます。理由はゲームの根本的な仕組みにあります。

### ターンメーターの仕組み

SWGoH のバトルはターン制です。各キャラクターは自分のスピード値に比例してターンメーター（TM）を蓄積し、**TM が 1000 に達したキャラクターが行動**します。

```
行動までのラウンド数 = 1000 ÷ スピード値
```

| スピード値 | 行動までのラウンド |
|:---:|:---:|
| 200 | 5ラウンド |
| 250 | 4ラウンド |
| 333 | 3ラウンド |

スピード250のキャラはスピード200のキャラが5回行動する間に6回以上行動できます。GAC（グランドアリーナ）やTW（テリトリーウォーズ）では、相手より先に動いてバフをかけたりデバフを入れたりすることが勝敗を直接左右します。

### スピードの良品基準

- **スピードプライマリ（アロー）**: 5ドットで+30、4ドットで+26
- **スピードセカンダリ**: 最大+30（非常にレア）、+15〜20が良品の目安
- スピードプライマリとスピードセカンダリは同じモッドに**同時に付かない**

## 第5章: セカンダリスタットとモッドの育て方

### 12種のセカンダリスタット

| セカンダリ | 重要度（スピード重視キャラ） |
|---|---|
| **スピード** | ★★★★★ 最重要 |
| 攻撃力%／攻撃力（フラット） | ★★★★ |
| クリティカル率% | ★★★ |
| 有効性% | ★★★（デバッファー） |
| 体力%／体力（フラット） | ★★ |
| プロテクション%／プロテクション（フラット） | ★★ |
| 防御力%／防御力（フラット） | ★（タンク向け） |
| 抵抗力% | ★（タンク向け） |

### モッドレベルの上げ方

モッドはレベル1〜15まで上げられます。クレジットを消費してレベルアップし、特定のレベルでセカンダリが追加・強化されます。

- **Lv3、6、9、12** でセカンダリスタットが1個追加または既存のセカンダリが強化される
- **Lv15** でセットボーナスが最大値になる

### 保持か売却かの判断

**モッドをLv12まで上げてスピードセカンダリを確認し、基準以下なら売却する**のが基本戦略です。

| モッドカラー | 保持するスピードセカンダリの目安 |
|---|---|
| パープル（B） | +8以上 |
| ゴールド（A） | +10以上 |

## 第6章: モッドの入手方法（2026年版）

> **注意**: 2026年5月の「Cantina 2.0」アップデートでMod Challengesが廃止されました。以下は現行システムの説明です。

### Cantina 2.0 モッドシステム

モッドの主な入手・強化はCantina（カンティーナ）内のMod Battlesで行います。

| ティア | 入手できるもの |
|---|---|
| **Tier 1** | 5ドットモッド（旧Mod Challenges相当） |
| **Tier 2** | スライス素材（旧Map 9相当） |

- まずはTier 1を繰り返してモッドのストックを増やす
- スライスを進めたい段階でTier 2に移行

### その他の入手先

- **ギルドストア**: Pulse Modulators（スライス素材）を購入可能
- **征服（Conquest）ストア**: 高品質なモッドが定期的に入手可能
- **GAC報酬**: シーズン報酬にモッドが含まれることがある

## 第7章: スライス（ドット数アップ）

スライスとは5ドットのモッドを6ドットに昇格させることです。スライスするたびにセカンダリスタットが強化されます。

### スライスの前提条件

- **Lv15** まで上げていること
- **5ドット** であること

### スライスの流れ（5E → 5A → 6E）

5ドットのモッドはカラー（ティア）を E → D → C → B → A の順に昇格できます。各昇格でセカンダリスタットが1個ランダムに強化されます。

**5Aから6Eへのスライスに必要な素材:**

| 素材 | 必要数 | 入手先 |
|---|:---:|---|
| Amplifiers | 50個 | Tier 2 Mod Battles |
| Capacitors | 50個 | Tier 2 Mod Battles |
| Pulse Modulators | 20個 | ギルドストア |

6Eに昇格した時点で、全プライマリとセカンダリのスタットが一括で上昇します。その後、6E → 6A のスライスをさらに続けることができます。

### スライスすべきモッドの基準

スライス素材は貴重なため、すべてのモッドをスライスするのは非効率です。

✅ **スライスする価値がある**:
- スピードセカンダリが出ているモッド
- セカンダリ合計値が高いゴールドモッド

❌ **スライスしない方がよい**:
- スピードセカンダリがゼロのモッド
- カラーがグレー・グリーンのモッド

### キャリブレーション（上級者向け）

2022年9月に追加された機能で、6ドットモッドのセカンダリスタットを別のスタットに移せます。「Micro Attenuators」という素材を消費します。不要なセカンダリをスピードに変換できる可能性があるため、優秀なモッドをさらに磨き上げたいときに使います。

## まとめ: 初心者がまず覚えること

1. **アロースロットには必ずスピードプライマリを装備**する
2. **Lv12まで上げてスピードセカンダリを確認**し、パープルで+8未満・ゴールドで+10未満なら売却
3. セットは**スピード4枚セット**を基本にキャラの役割で調整
4. Cantina の**Tier 1でモッドをファーム**し、スライスしたくなったらTier 2へ
5. スライスは**スピードセカンダリが出ているモッドを優先**する

モッド集めは長期戦です。焦らず、まずは主力キャラ（アリーナ・GAC用）から整えていきましょう。キャラ別の推奨モッドセットは [swgoh.gg のMod Meta Report](https://swgoh.gg/stats/mod-meta-report/) でトップ層のデータを確認できます。
