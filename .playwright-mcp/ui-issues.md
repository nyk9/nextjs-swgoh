## 🔴 Critical

### C-1: キャラクター検索が機能しない

- **ページ:** `/characters`
- **ファイル:** `src/hooks/serchFilter.ts`
- **現象:** 検索ボックスに文字を入力してもキャラクター一覧がフィルタリングされない。
- **原因:**
  1. `useSearchResults` の `useEffect` 依存配列に `char`（配列オブジェクト）が含まれており、毎レンダーで参照が変わる場合に無限ループが発生する。
  2. `useSearchTerm` が URL クエリパラメータ (`?q=`) をソースとして `router.replace` で更新する設計のため、上記の無限ループと組み合わさり URL 更新が連続発火し入力が無視される。
- **修正方針:**
  - `useEffect` + `setState` をやめ、`useMemo` で `searchResults` を直接導出する。
  - または `char` を `useRef` で安定化させる。

### C-2: `Maximum update depth exceeded` コンソールエラーが連続発生

- **ページ:** `/characters`
- **ファイル:** `src/hooks/serchFilter.ts` L35–49
- **現象:** ページ表示直後からコンソールに無限ループエラーが発生し続ける（調査中に30件以上蓄積確認）。
- **影響:** React が強制的にレンダリングを停止するリスクがあり、本番環境でも同様に発生している可能性が高い。
- **修正方針:** C-1 と同根。`useMemo` で `searchResults` を導出することで解消する。

## 🟠 High

### H-1: `/advisor` がヘッダーナビゲーションに存在しない

- **ファイル:** `src/components/layouts/header/Header.tsx`
- **現象:** ハンバーガーメニューに `/advisor`（育成アドバイス）が含まれておらず、ホームページのカードからしかアクセスできない。他ページから辿り着く方法がない。
- **修正方針:** `Header.tsx` の `MenubarContent` に `/advisor` へのリンクを追加する。

### H-2: `/about` ページだけライトテーマで世界観が崩壊

- **ファイル:** `src/app/about/page.tsx`
- **現象:** 背景が `bg-purple-200`（明るい紫）、コンテンツブロックが `bg-blue-500`（青）。他のページはダークグレー・ブラック基調で統一されているのにここだけ別サイトのような見た目になっている。
- **修正方針:** 背景を `bg-neutral-700` 等のダーク系に変更してサイトテーマに統一する。

### H-3: `/about` ページの情報が 2024 年のまま更新されていない

- **現象:**
  - 「2024/6/07 現在情報系の学部に通う大学3年生」が 2026 年現在も残っている。
  - 使用技術が `Next.js v.14.1.0` と記載されているが現在は `15.4.8`。
  - `/advisor`（AI アドバイザー）等の新機能追加が一切反映されていない。
- **修正方針:** 内容を現在の状況に合わせて更新する。バージョン情報は削除またはリポジトリの `package.json` から自動取得する。

### H-4: `/TWCounters` がデータ 1 件で画面の大半が空白

- **現象:** DB に 1 件のテストデータのみ。ページのほぼ全域が白い空白になる。空状態（Empty State）専用の UI が存在しない。ホームカードに「不具合多発のためご注意ください」とあるが、ページ自体は普通にアクセスできる。
- **修正方針:**
  - データ 0 件時に「まだカウンターが登録されていません」メッセージ＋入力フォームへの誘導を表示する。
  - または開発中であることを明示するバナーを追加する。

### H-5: キャラクタープロパティ文字がカードからはみ出て切れる

- **ファイル:** `src/app/characters/page.tsx` L203
- **現象:** 各カードのプロパティ説明（「ダークサイド、サポート、ドロイド、ならず者」等）が `<small>` タグで表示されており、4カラムレイアウト時にカード幅に対してはみ出してトランケートされる。
- **修正方針:** `truncate` クラスを外して折り返し表示にするか、ツールチップで全文表示する。

## 🟡 Medium

### M-1: 「押したボタン：属性: ,スキル効果:」がデバッグ表示のまま本番表示されている

- **ファイル:** `src/app/characters/page.tsx` L182–185
- **現象:** フィルターエリアの下に常時表示されている。値未選択時は `押したボタン： 属性: ,スキル効果:` と空のまま表示される。
- **修正方針:** 削除するか、選択中フィルターを示すバッジ表示（`ライトサイド ×`）に置き換える。

### M-2: ヘッダーメニューに「Ships（未実装）」が残っている

- **ファイル:** `src/components/layouts/header/Header.tsx` L34
- **現象:** 未実装ページへのリンクがナビゲーションに表示されており、クリックするとエラーページに飛ぶ可能性がある。ホームページのカードにも同様の問題がある。
- **修正方針:** 実装完了まで非表示にするか、グレーアウト＋`cursor-not-allowed`＋`Coming Soon`バッジで無効化する。

### M-3: フィルターパネルの閉じボタンがモバイルで極小

- **ファイル:** `src/app/characters/page.tsx` L72–75
- **現象:** `IoCloseOutline` アイコンのみでテキストラベルなし。ボタンサイズ指定がなく、推奨タップターゲット（44px）を大きく下回っている。
- **修正方針:** `min-w-[44px] min-h-[44px]` を付与するか、`p-3` 等でパディングを拡大する。

### M-4: キャラクター名が全て `<h1>` タグで SEO・アクセシビリティ違反

- **ファイル:** `src/app/characters/page.tsx` L193
- **現象:** 各カードのキャラクター名が `<h1>` で実装されており、1ページに数十個の `h1` が存在している。
- **修正方針:** `<h3>` または `<p>` に変更する。キャラクター詳細ページのスキル名 `<h1>` も同様に修正が必要。

### M-5: フィルターボタンに `sm:mt-20` が設定されてレイアウトが崩れる

- **ファイル:** `src/app/characters/page.tsx` L64
- **現象:** スモールブレークポイントで検索入力とフィルターボタンの間に不自然な大きな空白が生じる。
- **修正方針:** `sm:mt-20` を `sm:mt-0` または削除する。

### M-6: アドバイザーのウィザードで完了済みステップへ戻れない

- **ページ:** `/advisor`
- **現象:** 4ステップのウィザード（アライコード → モード → 目的 → チャット）において、完了済みステップへクリックで戻る機能がない。前のステップへ戻るには小さなテキストリンクのみに依存している。
- **修正方針:** ステップインジケーターをクリッカブルにするか、各ステップに「戻る」ボタンを追加する。

### M-7: `/TWCounters` でログイン状態に関わらず「ログイン」「入力フォーム」ボタンが表示される

- **現象:** 未ログイン状態でも「入力フォーム」ボタンが押せる状態で表示されている。クリック後の動作が不明確。
- **修正方針:** 認証状態に応じてボタンを表示/非表示切り替えるか、未ログイン時にはログインへリダイレクトする。

### M-8: カラーパレットがページごとにバラバラで統一感がない

- **現象:**

  | ページ | 背景色 |
  |--------|--------|
  | ホーム | `neutral-700` |
  | キャラクター | `neutral-500` |
  | TWCounters | `stone-700` + 白 |
  | アドバイザー | `stone-700` |
  | About | `purple-200` ← 別サイト状態 |

- **修正方針:** SWGoH 世界観に合わせたカラーシステムを `globals.css` または `tailwind.config` に定義し、全ページで統一する。

  ```css
  /* 推奨カラーパレット */
  --swgoh-bg-deep:     #0c0f1a;  /* 深宇宙ネイビー */
  --swgoh-bg-card:     #161b2e;  /* ダークスペースブルー */
  --swgoh-gold:        #FFD700;  /* ライトサイドゴールド */
  --swgoh-force-blue:  #4FC3F7;  /* ホログラム / フォース */
  --swgoh-sith-red:    #EF4444;  /* ダークサイド / シス */
  --swgoh-text:        #CBD5E1;  /* スターライト */
  --swgoh-subtext:     #64748B;  /* ネビュラグレー */
  ```

## 🟢 Low

### L-1: キャラクター詳細ページに「戻る」ボタンがない

- **ページ:** `/characters/[id]`
- **現象:** キャラクター詳細ページからキャラクター一覧へ戻る手段がブラウザバックまたはロゴクリックのみ。
- **修正方針:** ページ上部に `← キャラクター一覧へ` リンクを追加する。

### L-2: ホームのカードが 7 枚でグリッドが崩れる

- **ファイル:** `src/app/page.tsx`
- **現象:** `xl:grid-cols-4` の 4 カラムレイアウトで 7 枚のカードを配置すると 4+3 の配置になり、2 行目が左寄りになる。
- **修正方針:** カード数を 4 または 8 の倍数に調整するか、`justify-center` でカードを中央揃えにする。

### L-3: ホームのカード文字サイズに一貫性がない

- **ファイル:** `src/app/page.tsx` L19 vs L34
- **現象:** 「参考にしたサイト」カードは `text-2xl`、他カードは `text-3xl` で統一されていない。
- **修正方針:** 全カード統一のフォントサイズクラスを適用する。

### L-4: フッターの背景色がサイト全体のダーク統一から外れている

- **ファイル:** `src/components/layouts/footer/Footer.tsx` L7
- **現象:** `bg-slate-500`（ミディアムグレー）が使われており、ヘッダーの `bg-black` やコンテンツの `bg-neutral-700` と中途半端に異なる。
- **修正方針:** `bg-neutral-900` 等に変更してヘッダーと対称的なダーク配色にする。

### L-5: `Image unoptimized={true}` 警告が発生している

- **ファイル:** `src/app/characters/page.tsx` L201
- **現象:** 全キャラクター画像に `unoptimized={true}` が設定されており、Next.js の画像最適化が無効化されている。
- **修正方針:** 外部ドメイン（swgoh.gg 等）を `next.config.js` の `images.remotePatterns` に追加し、`unoptimized` を削除する。

### L-6: アップデートログが 2024 年で止まっている

- **ファイル:** `src/app/page.tsx`
- **現象:** アップデートログの最新が `2024/07/03`、実装予定も `2024/3/27` が最終。AI アドバイザー等の新機能追加が未反映。
- **修正方針:** 内容を最新状態に更新するか、アップデートログセクション自体を折りたたみ（accordion）にして画面占有を減らす。
